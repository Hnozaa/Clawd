# Clawd
Fan-made pixel pet of the Claude Code mascot for Windows. He sits on your taskbar and reacts to Claude Code hooks: types while Claude works, jumps when it needs you, celebrates when done. One 73 KB exe: no installer, network or registry. VirusTotal 2/71 (CrowdStrike ML 60%, MaxSecure generic), likely false positives. Not affiliated with Anthropic.
